# API contract matrix

The adapters in `apps/web/lib/api.ts` retain the existing `/api/v1` request and response shapes. `demoFetch` handles these paths in memory and stores state in the current tab's `sessionStorage`.

| Route family                                                            | Simulated operations                                                               | Access and behavior                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ----------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/auth/login`, `/auth/logout`, `/auth/me`                               | POST, POST, GET                                                                    | Six fictional accounts; shared demo password; logout resets tab state.                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `/contacts` and `/lead-sources`                                         | List, detail, create, update, archive, restore, related opportunities; source list | Read for all roles. Create for Admin, Manager, Sales, Operations, Triage. Sales/Manager/Admin edit broadly; Triage edits only records it created. Operations sees email/phone masked; kiosk reveal records an audit event.                                                                                                                                                                                                                                                                                                                          |
| `/companies`                                                            | List, detail, create, update, archive, restore, related contacts/opportunities     | Read for all; create for roles with contact-create access; edit/archive/restore for Admin, Manager, Sales.                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `/products`                                                             | List, detail, create, update                                                       | Authenticated reads; Admin writes. Seed catalog rates are public demo rates.                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `/opportunities`                                                        | List, detail, create, update, archive, restore, stage change, history              | All roles can read; Sales/Manager/Admin/Triage create. Manager/Admin can change any opportunity; Sales is scoped to owner; Triage is scoped to creator. Finance and Operations cannot change opportunities directly.                                                                                                                                                                                                                                                                                                                                |
| `/pipeline-stages`, `/users`, `/sales-representatives`, `/loss-reasons` | Read; Admin configuration writes where supported                                   | Opportunity readers can read. Pipeline, representatives, and global loss settings are Admin-controlled.                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `/activities`                                                           | List, detail, create, update                                                       | Opportunity readers can read and create notes. Admin/Manager/Sales edit; Sales is scoped to notes it created. System events cannot be edited.                                                                                                                                                                                                                                                                                                                                                                                                       |
| `/audit`                                                                | List and filter                                                                    | Admin only; writes from simulated operations are local to the current tab.                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `/dashboard/summary`, `/pipeline`, `/sources`, `/revenue`, `/drilldown` | Aggregated reads and filters                                                       | Opportunity readers see counts. Revenue is available to Admin, Manager, Sales, Finance. Probability is limited to Admin/Manager; drilldown is Admin-only. Operations/Triage economics are masked. Stage narrows summary, sources, and revenue; pipeline ignores that filter. Inquiry counts use creation dates, outcome/revenue metrics use close dates, and pipeline values are current snapshots. The source donut includes a null-source “No source” bucket; its drilldown uses `source_id=none`. Revenue is a dense 12-month series by default. |
| `/settings/loss-reason-required`                                        | Read and update                                                                    | Admin writes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `/kiosk/inquiries`, `/kiosk/contacts/:id`, `/kiosk/contacts/:id/reveal` | Create inquiry, narrow customer correction, PII reveal                             | Inquiry creation and profile correction are Operations/Admin. Reveal is audited and available to authenticated contact readers.                                                                                                                                                                                                                                                                                                                                                                                                                     |

Errors use the existing `{ error: { code, message, fields?, duplicates? } }` envelope. Validation returns 422, duplicate warnings return 409, and access failures return 403. Unimplemented paths fail locally with 404; the adapter does not proxy them.

This matrix describes the implemented demo subset. It is not a claim that the original server's full validation or transaction behavior is reproduced.
